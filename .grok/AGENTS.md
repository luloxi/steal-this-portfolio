# Portfolio agent rules

## Never use em dashes

- Do **not** use the character `—` (em dash) anywhere in user-facing content.
- Prefer: comma, period, colon, parentheses, or split into two sentences.
- Ranges: `2024 - Present` (hyphen), never `2024 — Present`.
- Same spirit for en dashes (`–`) as fancy separators in prose: avoid them.
- Applies always: ES and EN strings in `src/i18n/messages.ts`, components, README, commits messages if they appear on the site.

When editing copy, scan for `—` before finishing.
